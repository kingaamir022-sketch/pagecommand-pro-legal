Privacy Policy — PageCommand Pro

Effective date: 6 November 2026 · Meta app name: “PageCommand Pro Manager”

PageCommand Pro is a Page management tool that helps a Facebook Page administrator inventory, monitor and maintain the Pages they administer. The software runs on the user’s own computer and connects to Facebook only through Meta’s official APIs and OAuth login. This policy explains what data the app accesses, how it is used, and how it can be deleted.

1. Data we access

When a user connects a Facebook profile with “Connect with Meta”, the app requests only the permissions needed for its features. Through the official Meta Graph API the app can access:

  • Connected profile: the Facebook user ID and name of the profile the user chooses to connect.
  • Pages: the name, ID, public link, category and published status of the Facebook Pages that the connected profile can access, as returned by /me/accounts.
  • Page content metadata: for the duplicate-video feature, the text, creation date, duration, thumbnail and view counts of videos posted on those Pages.
  • Linked Instagram accounts: the username and ID of an Instagram professional account linked to a listed Page, where the API returns it.

The app never receives or asks for the user’s Facebook password, and it does not scrape Facebook or collect data about people who have not connected their own account.

2. How the data is used

  • To show the user an inventory of their Pages (grouped by the profile that has access), and to warn them if a Page disappears from a profile’s access.
  • To detect videos that were posted two or more times across the user’s own listed Pages, showing each copy’s Page, date and view count.
  • To delete a duplicate post only when the user explicitly confirms that action inside the app. Nothing is ever deleted automatically.

Data obtained through Meta APIs is used only inside the app for the features above. It is never sold, rented, or shared with third parties, and it is never used for advertising or for any purpose unrelated to the user’s own Page management.

3. Storage and security

PageCommand Pro runs locally: the inventory, scan results and history are stored in the app’s data folder on the user’s own computer, not on our servers. Meta access tokens are stored encrypted at rest (AES-256-GCM). App accounts are protected by salted, hashed passwords, and access to the app is limited to the accounts the app owner creates or approves.

4. Data retention and deletion

Data is kept only while the user keeps it in the app. A user can at any time:

  • Disconnect a profile or delete Pages, profiles and the app’s data folder directly inside the app / on their own computer — this permanently removes the locally stored data.
  • Remove the app’s access entirely in Facebook: Settings → Business integrations / Apps and websites → “PageCommand Pro Manager” → Remove. This revokes all tokens immediately.
  • Request deletion of any data held about them in connection with this app by emailing aalisrajpoot@gmail.com with the subject “Data deletion request”. Requests are actioned within 30 days and confirmed by reply.

5. Children

The app is a business tool for Page administrators and is not directed at children under 13. It does not knowingly collect data about children.
